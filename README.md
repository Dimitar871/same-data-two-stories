# Same Data, Two Stories

How visualization choices shape the perceived truth of UFC grappling vs. striking.

A university data visualization report, made as coursework for the
Data Visualization course.

## About

The same real UFC fight data (1994–2025) is shown twice: once in a way that is
biased toward grappling, and once in an honest way. Four misleading techniques
are demonstrated:

1. Truncated axis (bar chart)
2. Part-to-whole framing (pie chart)
3. Cherry-picked time range (line chart)
4. Area-size distortion (bubble chart)

The data is never changed, only the way it is presented.
